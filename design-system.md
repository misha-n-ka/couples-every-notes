# Design system — Couples Dashboard

Практическая дизайн-система проекта. Она продолжает направление «Лаванда и абрикос» из [`design.md`](./design.md) и задаёт единое поведение для карточек, кнопок и интерактивных поверхностей.

## Принципы

- Состояние элемента должно быть понятно по движению, тени, границе или тексту, а не только по цвету.
- Одинаковые по роли элементы используют один компонент и одни состояния.
- Карточка «Вечер кино дома» — эталон интерактивной карточки события: при наведении она слегка поднимается, при нажатии возвращается на место и получает более плотную тень.
- Цвет темы карточки сохраняется во всех состояниях; hover и pressed меняют геометрию и тень, а не смысл темы.

## Токены

Все базовые токены находятся в [`app/globals.css`](./app/globals.css). Значения указаны в CSS, чтобы компоненты и экраны использовали один источник правды.

## Карточки и интерактивные поверхности

Базовый компонент — `Card` из [`components/ui/card.tsx`](./components/ui/card.tsx). Для кликабельной карточки используется `interactive`:

```tsx
<Card interactive onClick={openDetails}>
  ...
</Card>
```

Единое поведение задаёт класс `interactive-surface` в `app/globals.css`:

| Состояние | Поведение                                                                                    |
| --------- | -------------------------------------------------------------------------------------------- |
| Default   | Радиус 24px, обычная тень карточки                                                           |
| Hover     | `translateY(-2px)` и мягкая тень `--shadow-card-hover`                                       |
| Pressed   | Возврат к `translateY(0)` и тень `--shadow-card-pressed`                                     |
| Focus     | Кольцо 2px цвета `--ring` с зазором 2px                                                      |
| Disabled  | Не использовать для карточек без явной причины; действие должно быть недоступно семантически |

Строки событий и компактные элементы, которые не являются `Card`, используют тот же класс `interactive-surface`. Не добавляй отдельные `hover:-translate-y-*` для конкретного экрана.

## Кнопки

Все кнопки проходят через [`components/ui/button.tsx`](./components/ui/button.tsx). Новый визуальный стиль кнопки не добавляется на странице вручную.

### Варианты

| Вариант       | Назначение                                |
| ------------- | ----------------------------------------- |
| `default`     | Главное действие текущего блока           |
| `secondary`   | Выбранная вкладка или вторичное действие  |
| `outline`     | Нейтральное действие рядом с основным     |
| `ghost`       | Ненавязчивая навигация и действия в шапке |
| `destructive` | Удаление и опасные действия               |
| `link`        | Текстовая ссылка                          |

Все варианты имеют одинаковую механику: плавный переход 150ms, hover через соответствующий цветовой токен, pressed со сдвигом вниз на 1px, focus-visible с кольцом. Скругление по умолчанию — 12px; `rounded-full` разрешён только для пилюль и круглых иконок.

### Размеры

`xs` — компактные служебные действия, `sm` — небольшие элементы, `default` — основной интерфейс, `lg` — заметное действие в hero-блоке, `icon` — квадратная кнопка с иконкой. Текстовые кнопки не должны вручную задавать собственные высоту и padding без необходимости.

## Типографика и доступность

- Заголовки используют текущий округлый sans-serif проекта; основной текст — тот же шрифт с обычным начертанием.
- Обычный текст должен сохранять контраст не ниже 4.5:1.
- Hover и pressed дополняются фокусом, текстом или иконкой; цвет не является единственным признаком состояния.
- Кликабельные карточки имеют `role="button"`, `tabIndex={0}` и реагируют на Enter/Space, если они не являются настоящей кнопкой.
- Иконки в кнопках не заменяют подпись действия; для иконки без текста используется `aria-label`.

## Правило расширения

Если новый экран требует нового значения радиуса, отступа или состояния, сначала проверь, можно ли выразить его существующим токеном. Новый токен добавляется только вместе с причиной и примером использования в этом документе.
