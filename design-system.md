# Design system — Couples Dashboard

Канонический контракт визуального слоя. Продуктовые решения и UX-сценарии находятся в [`design.md`](./design.md). CSS-значения живут в [`app/globals.css`](./app/globals.css), поэтому компоненты не создают собственные палитры.

## Принципы

- Роль важнее значения. Экран выбирает `surface`, `text`, `action` или `feedback`, а не новый HEX.
- Состояние читается по фокусу, тексту, границе или движению. Цвет не бывает единственным сигналом.
- Одинаковые по роли элементы используют один UI-компонент и одинаковые состояния.
- Цвет темы заметки описывает тему, а подпись и иконка описывают доступ.

## Токены

### Семантические роли

| Группа              | Токены                                                                                                                             | Назначение                                                    |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------- |
| Поверхности         | `--surface-app`, `--surface-card`, `--surface-muted`, `--surface-secondary`, `--surface-accent`                                    | Фон приложения, карточки, вторичные блоки и акцентные области |
| Текст               | `--text-primary`, `--text-secondary`, `--text-on-primary`, `--text-on-secondary`, `--text-on-accent`                               | Основной, вторичный и контрастный текст                       |
| Действия            | `--action-primary`, `--action-primary-hover`, `--action-primary-pressed`, `--action-secondary-hover`, `--action-secondary-pressed` | Основная и вторичная кнопка в состояниях                      |
| Системные состояния | `--border-default`, `--focus-ring`, `--feedback-danger`                                                                            | Границы, фокус и ошибки                                       |
| Движение и глубина  | `--motion-fast`, `--elevation-card`, `--elevation-card-hover`, `--elevation-card-pressed`                                          | Общая длительность и тени интерактивных поверхностей          |

Базовые имена `--background`, `--primary`, `--muted` и другие остаются алиасами для установленных UI-примитивов. Новые компоненты используют семантическую роль, когда она доступна.

### Тёмная тема

Класс `.dark` переопределяет те же семантические роли, поэтому компоненты не добавляют отдельную палитру для каждого состояния. По умолчанию `next-themes` использует системную тему. Переключатель в шапке позволяет выбрать светлую или тёмную тему и сохраняет явный выбор пользователя. Пастельные заливки тем получают более глубокие оттенки, а текст и фокус сохраняют контраст.

### Тема заметки

`--lavender`, `--apricot`, `--rose`, `--sage` и `--sky` — единственные заливки тем. Они не определяют видимость записи. Не добавляй пользовательский выбор цвета в MVP.

### Геометрия

| Токен                   | Значение          | Использование                                |
| ----------------------- | ----------------- | -------------------------------------------- |
| `--radius-card`         | `24px`            | Карточки и крупные поверхности               |
| `--radius-control`      | `12px`            | Кнопки, поля и небольшие элементы управления |
| `--radius-pill`         | `999px`           | Бейджи, фильтры и круглые действия           |
| `--space-1`…`--space-8` | шаги `4px`…`32px` | Ритм внутренних и внешних отступов           |

Внешнее поле страницы — 16px на телефоне и 32px на широком экране. Новое значение добавляется только с причиной и примером использования.

## Компоненты и состояния

`Button` из [`components/ui/button.tsx`](./components/ui/button.tsx) — единственная точка для кнопок. `Card` из [`components/ui/card.tsx`](./components/ui/card.tsx) — базовая точка для карточек. Для кликабельной карточки передай `interactive`.

```tsx
<Card interactive onClick={openDetails}>
  ...
</Card>
```

Класс `interactive-surface` задаёт общую механику для карточек и строк событий.

| Состояние | Контракт                                                          |
| --------- | ----------------------------------------------------------------- |
| Default   | Радиус `--radius-card` и тень `--elevation-card`                  |
| Hover     | Подъём на 2px и `--elevation-card-hover`                          |
| Pressed   | Возврат на место и `--elevation-card-pressed`                     |
| Focus     | Кольцо 2px цвета `--focus-ring` с отступом 2px                    |
| Disabled  | Недоступность задаётся семантически и сохраняет читаемый контраст |

Кликабельный элемент, который не является кнопкой, получает `role="button"`, `tabIndex={0}` и обработку Enter/Space. Иконка без подписи получает `aria-label`.

## Типографика и доступность

Проект использует системный sans-serif с округлым характером для заголовков и читаемым начертанием для основного текста. Подключение Nunito и Golos Text остаётся отдельной задачей, описанной в `design.md`.

Обычный текст сохраняет контраст не ниже 4.5:1. Интерактивные состояния дополняются фокусом, границей, текстом или движением. Любое новое цветовое сочетание нужно проверить до добавления в экран.

## Правило расширения

Перед добавлением класса проверь, выражается ли решение существующим токеном или базовым компонентом. Если нет, добавь один токен в `app/globals.css`, объясни его роль здесь и укажи конкретный экран-потребитель.
