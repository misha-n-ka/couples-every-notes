# Couples Dashboard

Личное веб-приложение для пары: совместные желания и планы, личные списки и приватные идеи сюрпризов в одном месте.

Первая версия предназначена для двух участников с заранее созданными аккаунтами и будет работать в браузере на телефоне и компьютере. Проект также служит практикой изучения TypeScript, React и Next.js с нуля.

## Текущее состояние

Завершён этап исследования и дизайна: изучены шесть аналогов, описаны UX-сценарии, навигация и дизайн-система. План дизайн-этапа утверждён пользователем. Результат и границы проверки сохранены в [design.md](design.md).

Приложение пока не реализовано. Все 24 требования MVP остаются Pending; план реализации ещё предстоит подготовить. Зависимости не установлены, команд запуска и сборки пока нет.

## Возможности первой версии

- Вход по логину и паролю под одним из двух заранее созданных аккаунтов.
- Общее пространство пары и личное пространство каждого участника.
- Создание, просмотр, изменение и удаление заметок с названием, описанием и необязательной ссылкой.
- Темы заметок: подарки, еда, хобби, фильмы и сериалы.
- События на основе заметок: на весь день либо с началом, окончанием и выбранным часовым поясом. Поддерживаются события через полночь.
- Скачивание отдельного события в `.ics` для импорта в Google Календарь; системная передача файла при поддержке браузером. Экспорт создаёт разовую копию без синхронизации календарей.
- Сохранение данных между сеансами и сохранение участников, пространства, авторства и прав при будущем развитии авторизации.

Это согласованный объём будущего приложения, а не список уже работающих функций.

## Пространства и приватность

| Режим записи | Кто видит | Кто изменяет и удаляет |
|---|---|---|
| Общее | Оба участника | Оба участника |
| Видно партнёру | Автор и партнёр | Только автор |
| Только мне | Только автор | Только автор |

Эти правила распространяются и на события. Расширение доступа требует подтверждения. Сохранение общей записи в личное пространство создаёт независимую копию; исходник остаётся общим.

## Интерфейс

Основные разделы — **Главная · Заметки · События**. В заметках доступны **Общее · Моё · Партнёра**.

Главная показывает ближайшие события и последние заметки, кроме приватных записей. Свои приватные записи доступны в «Моём», а приватные события также в календаре. Чужие приватные записи недоступны.

События представлены календарной сеткой месяца. Навигация расположена снизу на телефоне и слева на компьютере; создание и редактирование открываются в полноэкранной форме на телефоне и окне на компьютере. Визуальное направление — светлая тема, пастельная палитра «Лаванда и абрикос» и мягкие формы.

## Выбранный стек

| Область | Технологии |
|---|---|
| Приложение | Next.js, React, TypeScript |
| Вход и сессии | Better Auth |
| Хранение | PostgreSQL, Drizzle |
| Размещение | Управляемый облачный сервис; провайдер и тариф не выбраны |

Стек согласован; конкретные совместимые версии ещё не определены.

## За пределами MVP

Пользовательские шаблоны и цвета карточек, изображения, задачи и исполнители, другие пары, открытая регистрация, отдельные приложения для других платформ и тёмная тема отложены. Полный список будущих улучшений приведён в требованиях.
